# Pet-GPT

> 입양부터 마지막 인사까지, 반려동물의 생애주기를 함께 돌보는 통합 케어 웹 서비스

Pet-GPT는 반려동물을 키우며 마주하는 여러 순간 — 입양, 식단 관리, 건강 기록, 용품 구매, 그리고 마지막 인사 — 을 한곳에서 돕는 플랫폼입니다. 사용자의 위치를 기준으로 주변의 보호소, 용품점, 장례식장 같은 장소를 연결해 주는 데 초점을 맞췄습니다.

🔗 **배포 주소**: [https://projectpetgpt-namcr7wezdjxbbsvdscdas.streamlit.app/)

## 주요 기능

Pet-GPT는 6개의 서비스 페이지와 홈 대시보드로 구성됩니다.

### 홈
- 등록한 반려동물을 카드로 한눈에 확인
- 로그인 시 다가오는 케어 일정을 D-day로 표시
- 각 서비스로 바로 이동하는 메뉴 카드

### 1. 가족 찾기 (입양)
- 주거 환경, 활동량, 알러지 등 간단한 설문으로 잘 맞는 품종 추천 (강아지·고양이 TOP 3)
- 품종별 상세 정보 제공 (기대 수명, 월 양육비, 대표 질환, 털 빠짐 등)
- 지역(시/도 → 시군구 → 동) 기반 입양 가능한 보호소·센터 안내

### 2. 맞춤 식단
- RER·MER 기반 하루 권장 칼로리 자동 계산
- 반려동물 프로필 등록 및 영구 저장 (다묘·다견 관리)
- 건강 고민별 추천 영양 성분 안내
- 반려동물이 주의해야 할 위험 음식 목록

### 3. 용품점 찾기
- 지역 기반으로 가까운 용품점·미용실을 지도와 목록으로 표시
- 가게 종류 필터링 (용품점 / 미용실)
- 전화 걸기·길찾기(카카오맵) 바로 연결
- 로그인 시 즐겨찾기 저장

### 4. 건강 수첩
- **케어 일정**: 예방접종·구충·미용 등 반복/단발 일정을 달력 UI로 관리, 완료 처리
- **진료 기록**: 병원·진단·처방·비용 기록 및 CSV 내보내기
- **투약 관리**: 매일·매주·매월·매년 주기로 복약 일정 등록, 오늘 먹을 약 체크

### 5. 마지막 인사 (추모)
- 지역 기반 반려동물 장례식장 안내 (정식 허가 시설 표시)
- 시설 유형 필터 (개별 화장, 봉안당)
- 장례 절차 안내 및 비대면 상담 신청
- 추억 앨범: 대표 사진과 추억 타임라인 기록 (로그인 시)

### 6. 이야기 나누기 (게시판)
- 반려인들과 노하우·고민을 나누는 커뮤니티
- 닉네임 로그인 또는 익명(게스트)으로 글·댓글 작성
- 본인이 쓴 글·댓글 삭제

## 프로젝트 구조

```
Project_PetGPT/
├── app.py                  # 진입점: 사이드바 메뉴(한글) 정의 및 라우팅
├── home.py                 # 홈 화면 (대시보드)
├── db.py                   # SQLite 연결 및 모든 DB 함수
├── auth.py                 # 닉네임 로그인 + 사이드바 위젯
├── utils.py                # 지역 선택·필터 공용 함수
├── requirements.txt        # 의존성 목록
├── .streamlit/
│   └── config.toml         # 색 테마 (베이지·뉴트럴)
├── pages/
│   ├── 1_adoption.py       # 가족 찾기
│   ├── 2_diet.py           # 맞춤 식단
│   ├── 3_shop.py           # 용품점 찾기
│   ├── 4_health.py         # 건강 수첩
│   ├── 5_memorial.py       # 마지막 인사
│   └── 6_board.py          # 이야기 나누기
└── data/
    ├── breeds.csv          # 품종 정보
    ├── petshop.csv         # 입양처(보호소·센터)
    ├── stores.csv          # 용품점·미용실
    ├── facilities.csv      # 장례식장
    └── comfort_message.csv # 위로 메시지
```

> 파일 이름은 영어로 두어 URL을 깔끔하게 유지하고, 사이드바에 보이는 메뉴 이름만 한글로 표시합니다.

## 실행 방법

### 1. 저장소 클론
```bash
git clone https://github.com/slasticzeta/Project_PetGPT.git
cd Project_PetGPT
```

### 2. 의존성 설치
```bash
pip install -r requirements.txt
```

### 3. 앱 실행
```bash
streamlit run app.py
```

실행하면 브라우저에서 앱이 열립니다. 진입점은 `main.py`가 아니라 **`app.py`** 입니다.

## 데이터 저장 방식

- 사용자 데이터(반려동물, 일정, 진료·투약 기록, 즐겨찾기, 추억 앨범, 게시글)는 SQLite(`data/petgpt.db`)에 저장됩니다.
- 로그인은 비밀번호 없이 **닉네임으로 사용자를 구분**하는 가벼운 방식입니다. (향후 카카오 등 OAuth로 교체할 수 있도록 설계)
- 비로그인 사용자는 게스트로 동작하며, 개인 데이터(반려동물·즐겨찾기·앨범)는 로그인 후 이용할 수 있습니다.

### 데이터베이스 테이블
`users`, `pets`, `schedules`, `records`, `favorites`, `album_photo`, `album_memories`, `medications`, `posts`, `comments`

> ⚠️ `petgpt.db`는 `.gitignore`에 포함되어 있어 저장소에 올라가지 않습니다. 각 실행 환경마다 DB 파일이 새로 생성되며, Streamlit Cloud에서는 재배포 시 초기화될 수 있습니다.

## 설계 메모

- **위치 입력은 GPS가 아닌 드롭다운**(시/도 → 시군구 → 동) 방식으로, 권한 요청 없이 누구나 바로 사용할 수 있습니다.
- 모든 장소 페이지(입양·용품점·추모)는 동일한 지역 선택·필터 로직(`utils.py`)을 공유합니다.
- 지도 마커의 팝업에는 전화·길찾기 링크를 두고, 즐겨찾기 별표는 목록 카드에 배치했습니다.
- 현재 데이터는 부산 지역을 중심으로 구성되어 있습니다.
